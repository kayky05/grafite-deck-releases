# Grafite Deck

Controle do OBS pelo celular Android, pelo Wi‑Fi (obs-websocket v5).

## Instalar

Baixe a versão mais nova pelo celular:

**https://github.com/kayky05/grafite-deck-releases/releases/latest/download/GrafiteDeck.apk**

Abra o arquivo baixado e toque em **Instalar** (ou **Atualizar**). Na primeira vez o Android pede para liberar a instalação pelo navegador.

## Conectar

No PC: OBS → Ferramentas → **Configurações do servidor WebSocket** → **Mostrar informações de conexão**. No app, toque em **LER QR DO OBS**. Celular e PC no mesmo Wi‑Fi.

---

Este repositório guarda só os APKs publicados. O `versao.json` é lido pelo app para avisar quando sai versão nova.
